# Ahmed El Khier Lemaoui

I build WhatsApp and Instagram chatbots, and automate the repetitive work around them. Based in Algiers, founder of **Kairos**.

My chatbots answer in French, Algerian Darija and Arabic, from a sheet the business approves. When the answer isn't there, they ask for the client's contact so a person can follow up.

### How I work

- A person stays in control: drafts, approval queues and handover instead of blind automation.
- Checks in code, not only in the prompt: arithmetic, language and format are verified before anything goes out.
- I worked in wholesale, stock and hotel operations before building software, so I start from the job to be done.
